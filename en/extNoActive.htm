Non-Activating Mode
Non-Activating Mode allows you to keep CLaunch visible while continuing to use the keyboard in other applications.
When using plugins such as Window Operations or Keyboard Actions to control the active window by clicking buttons in CLaunch, you need to switch to Non-Activating Mode.

To switch to Non-Activating Mode, select Non-Activating Mode from the Main Menu.
While in Non-Activating Mode, CLaunch cannot be operated using the keyboard.
If you enable Transparent only when inactive in the Design 1 tab of the Options dialog, you can visually distinguish the current mode (normal / non-activating).
By assigning the special item Show Without Activating to a button, and assigning a Hotkey or Direct Mouse Launch to that button, you can display CLaunch temporarily in a non-activating state.
